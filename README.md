# 바나나콕 코트 보드

배드민턴 모임에서 방을 만들고 6자리 코드로 입장해, 코트·게임 대기자·참석자를 여러 사람이 실시간으로 함께 보고 고치는 팀 편성 보드입니다.

- 방 만들기 / 코드로 입장하기
- 자동 편성: 게임 수가 적은 사람, 오래 기다린 사람 먼저. 최근에 같이 친 사람끼리는 되도록 다시 묶지 않음
- 편성 방식: 실력 밸런스 / 비슷한 급수끼리 / 같은 성별끼리(남복·여복)
- 휴식: 누르면 자동 편성에서 빠짐. 대기 경기에 있던 사람은 바로 다른 사람으로 교체, 경기 중이면 끝난 뒤부터 휴식
- 대기 경기의 이름을 눌러 사람 바꾸기, 코트 타이머, 경기 기록
- 방에 들어온 사람은 누구나 편성·수정할 수 있고, 모든 화면에 바로 반영됩니다

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `app.js` | 동작 (편성, 휴식, 실시간 저장) |
| `firebase-config.js` | Firebase 연결 설정값 — **처음 한 번 채워야 함** |
| `firestore.rules` | Firebase 데이터베이스 접근 규칙 |
| `assets/` | 캐릭터 이미지 |

## 처음 설정 (한 번만)

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에서 구글 계정으로 로그인 → **프로젝트 추가** → 이름 예: `bananakok-board` → Google 애널리틱스는 꺼도 됩니다.
2. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**로 시작.
3. Firestore의 **규칙** 탭에 이 저장소의 `firestore.rules` 내용을 전부 붙여 넣고 **게시**.
4. 프로젝트 개요 옆 ⚙ **프로젝트 설정 → 내 앱 → 웹(</>)** 으로 앱 등록 → 나오는 `firebaseConfig` 값을 `firebase-config.js` 에 붙여 넣기.

### 2. GitHub Pages 켜기
저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)`** → Save.
1~2분 뒤 `https://아이디.github.io/bananakok-board/` 에서 열립니다.

## 수정하면 어떻게 반영되나요?
- **명단·코트·대기 변경**: 페이지에서 누르는 즉시 Firebase에 저장되고, 같은 방에 들어와 있는 모든 화면에 새로고침 없이 바로 보입니다.
- **디자인·기능(코드) 수정**: GitHub에서 파일을 고쳐 커밋하면 1~2분 뒤 사이트에 자동 반영됩니다. 열어 둔 화면은 새로고침하면 새 버전이 보입니다.
